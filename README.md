# 🪦 Projectyard

**Кладбище заброшенных пет-проектов.** У каждого разработчика есть репозитории, которые он так и не доделал. Удалять жалко, архивировать скучно. Здесь их можно **похоронить**: вставляешь ссылку на репозиторий, проходишь маленькую церемонию и получаешь свидетельство о смерти проекта.

🌐 **[projectyard-bury.vercel.app](https://projectyard-bury.vercel.app)** · 📣 [Telegram-канал](https://t.me/z1mo0x_dev)

*English: a graveyard for abandoned side projects. Paste a GitHub repository link, bury it, and get a shareable certificate of death. The site is also available in English at `/en`.*

---

## Как это работает

1. **Вставь ссылку** на заброшенный репозиторий на GitHub.
2. **Выбери причину смерти** («выгорание», «пропал интерес», «разросся скоуп», «нашлась идея получше») и напиши эпитафию.
3. **Пройди похороны**: гроб, земля, тишина.
4. **Получи свидетельство**: сколько проект прожил, сколько в нём коммитов, каким был последний коммит и какими были последние слова.

Свидетельством можно поделиться: у него есть красивая картинка для соцсетей и отдельный формат для сторис.

## Что ещё есть

- **Бейдж для README.** Можно повесить на репозиторий плашку «projectyard | прожил 11 месяцев»: на странице свидетельства есть готовая строка, её остаётся вставить.
- **Счётчик могил.** Сайт собирает первые 100 проектов. Когда они наберутся, начнётся разработка основного Projectyard, куда похороненные проекты переедут: там брошенное можно будет передать тому, кто захочет доделать.
- **Русский и английский.** Весь сайт и все свидетельства открываются на обоих языках.
- **Удалить или пожаловаться.** Если твой проект похоронили без спроса или могила кажется неуместной, на странице свидетельства есть форма. Каждое обращение читает человек. После отправки можно получить ответ в Telegram.

## Без регистрации

Войти не нужно, платить не нужно. Достаточно ссылки на репозиторий и ника на GitHub. Известные проекты (больше 1000 звёзд) не хоронят: это уже не пет-проекты.

## Сделано на

Next.js, React, TypeScript, Tailwind CSS, Supabase. Картинки свидетельств рисуются кодом, звук в промо-ролике тоже синтезирован кодом, без сэмплов.

## Запустить у себя

```bash
npm install
npm run dev
```

Сайту нужна база Supabase и несколько переменных окружения (пример в `.env.example`). Подробная настройка, устройство проекта, Telegram-бот и всё для разработчиков описаны в [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
